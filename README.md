# 🌺 Mālama Map

**ハワイ在来植物を守る市民マップ**

*Mālama（マラマ）＝ハワイ語で「守る・世話をする」*

🌐 **日本語** | [English](README.en.md)

---

## これは何？

**Mālama Map** は、ハワイの植物の目撃情報を市民が投稿・共有する Web アプリです。

撮った写真を **AI（BioCLIP）** が種を判定し、**在来種**（ハワイ固有の植物）と **外来種**（森を脅かす植物）を見分けます。みんなの投稿が集まることで、外来種の広がりや **ROD（ʻŌhiʻa の急性枯死病）** の早期発見につなげることを目指しています。

> 🎯 使命：消えていくハワイの在来植物を記録し、外来種の侵食を市民の力で見つける。

---

## 主な機能

### 🗺️ 地図 Map
目撃された植物がピンで表示されます。ピンをタップすると写真・種名・AIの判定確率が見られます。

| ピンの色 | 意味 |
|---|---|
| 🟢 緑 | 在来種 Native |
| 🔴 赤 | 外来種 Invasive |
| ⚪ 白 | ROD 疑い（ʻŌhiʻa の枯死病） |
| ⚫ 灰 | 未確認 Unconfirmed |

### 📖 植物図鑑 Plants
図鑑（Pokédex方式）で、見つけた植物が集まっていきます。

- 🔓 **発見済み**（投稿された種）／🔒 **未発見**
- 在来種・外来種それぞれの **達成率（%）** を表示
- カードをタップすると詳しい情報とその種の目撃マップが見られます

### 📷 投稿 Report
見つけた植物を写真で記録して、地図と図鑑に反映します。

---

## 使い方（3ステップ）

### ① 写真を撮る／選ぶ 📷
「投稿」ページで植物の写真を撮るか選びます。
AI が候補の種を表示するので、その中から選びます。分からなければ **「未確認」でOK**。

> ✂️ **複数の植物が写っているとき**は「範囲を選ぶ」で、判定したい **1株まるごと**（葉と株の姿ごと）を囲むと精度が上がります。

### ② 場所を選ぶ 📍
地図で目撃した場所をタップします。
写真に位置情報が入っていれば、**「ここですか？」と自動でサジェスト**します。「現在地を使う」ボタンでも設定できます。

### ③ 投稿する ✅
種名・場所・メモを確認して投稿。
新種を見つけると **「じゃじゃーん！」の発見演出**が出て、図鑑が埋まり、地図にピンが追加されます。

## ちょっとした豆知識

- AI（BioCLIP 2.5）は、**追加学習なし**でも約2億枚の生物画像から学んだ知識を使い、ハワイ固有の植物を識別します。
- 花のアップだけだと近縁種と間違えやすいので、**葉や株全体を含めて**撮るのがコツです。
- 確信度が低いときは無理に断定せず、「未確認」としてコミュニティの確認に回します（＝自信満々の誤答を出さない設計）。

## メモ

- これは **フェーズ1（デモ版）** です。
- 投稿データは **この端末の中（localStorage）** に保存されます（まだ共有サーバーはありません）。
- AI 判定にはローカルの BioCLIP サーバーが必要です（未起動でも「未確認」として投稿は可能）。
